## Key Visual Elements (for our remake's style)

- **Board layout**: Ring of buildings connected by winding roads, colorful VGA palette
- **Buildings**: Detailed pixel-art structures with signage (neon, hand-painted style)
- **UI modals**: Pop over the board, feature character portraits + action menus
- **Bottom bar**: Clock (time remaining), week counter, calculator-style money display
- **Color palette**: Rich saturated VGA colors — deep blues, warm greens, earth tones
- **Typography**: Mix of pixel fonts and stylized hand-drawn lettering for locations
- **Locations visible**: LeSecurity (home), Rent Office, Low-Cost Housing, Pawn Shop, Z-Mart, Monolith Burgers, QT Clothing, Socket City, Black's Market, Bank, Employment Office, Factory
