# Art Inspiration & Asset Generation Guide

These images are AI-generated references inspired by the classic early 90s Sierra VGA pixel-art style. They serve as style targets for generating our own game assets.

## Style Description

- **Era**: Early 1990s VGA (256-color) pixel art
- **Perspective**: Isometric/bird's eye for buildings, front-facing for characters
- **Palette**: Rich saturated colors, visible dithering, warm earth tones for paths
- **Buildings**: Chunky, detailed, with clear signage and personality
- **Characters**: Semi-realistic pixel art (like Sierra's digitized actor style reimagined)
- **Environment**: Green grass, dirt paths, evergreen trees, flowers

## Assets Needed

### Building Tiles (128×128 or 256×256 PNG, transparent background)
Generate each separately for use as individual game tiles:

1. **Home** — small apartment/house, cozy, modest
2. **Rent Office** — brick office building with "RENT" sign
3. **Pawn Shop** — quirky storefront with golden balls sign
4. **Z-Mart** — large blue discount store
5. **Monolith Burgers** — fast food joint with big "M" (NOT McDonald's arches)
6. **QT Clothing** — purple/pink fashion boutique
7. **Socket City** — blue electronics store with lightning bolt
8. **University** — grand gothic/classical academic building
9. **Employment Office** — brown brick office, "JOBS" sign
10. **Factory** — industrial building with smokestacks
11. **Bank** — classical stone building with columns, vault-like
12. **Black's Market** — green-awning grocery/market store
13. **Entertainment** — movie theater / arcade, neon lights

### Characters (256×512 PNG, transparent background)
- **Player** — casual 90s young adult (white tee, jeans)
- **Jones** — distinct opponent character (different clothes/style)

### Board Background (1200×800 PNG)
- Green grass with dirt/gravel paths forming a ring
- Trees and bushes for decoration
- No buildings (we overlay those)

## Suggested Prompt Template

```
Pixel art [BUILDING NAME], early 1990s VGA game style, 256-color palette,
isometric view, detailed with visible pixels, [DESCRIPTION], transparent
background, game asset sprite, Sierra On-Line style
```
